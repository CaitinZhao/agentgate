# 新建题库：私有/公共、批量导入与开源改编

本文档说明创建一个新题库的完整流程：两种可见性、三种加题方式、领域包的一次性配置，
以及出题时的 AI 起草。修改已有题库与字段含义见 [修改题库与出题字段](bank-edit.md)；
开源数据集的下载细节见 [开源题库下载使用](public-banks.md)。

## 1. 新建 benchmark 向导（题库页 → 新建 benchmark）

| 步骤 | 填什么 | 说明 |
|---|---|---|
| ① 基本信息 | 名称（小写字母/数字/连字符，即库的唯一 id）、显示名、可见性、领域分组、默认 level、简介 | **公共**：全平台可见，admin 才能创建和管理；**私有**：仅创建者与 admin 可见，member 也可创建 |
| ② 建题方式 | 空库 / Excel 批量 / 外部数据集 | 空库=之后在详情页加题；Excel=下载模板→填写→上传（标红回传循环）；外部数据集=autoadapt 自动分桶 |

创建后进入题库详情页。私有库的题目直接编辑；公共库走"编辑题库"页（admin/owner）。

## 2. 三种加题方式

1. **在线单题**（编辑题库页 → 添加新题）：填 query + gold，见
   [修改题库与出题字段](bank-edit.md) 的字段详解。适合小批量与精修。
2. **Excel 批量**（编辑题库页 → 批量导入）：下载空白模板（或导出已有库再改）→ 填写
   （多值列用中文分号"；"分隔，level/题型列有下拉）→ 上传；有问题的行返回**标红文件**
   （错误单元格红底 + 错误说明列），改对后原文件重传，循环到 0 问题才入库。
3. **外部数据集（autoadapt）**：上传 jsonl/csv（至少 id/问题/金标三列）或给数据集 URL，
   填字段映射与剖面 → 自动分桶（数值/是非/自由文本）成 gold v2 题，并生成人工检查清单
   （分桶是否正确、金标解析是否正确）。自由文本题的 rubric 即数据集金标答案。

## 3. AI 起草（可选，需用户中心配置 AI）

- **出题表单里"✨ AI 起草 gold"**：粘贴题面 + 材料原文（或数据集金标），AI 判定题型、
  抽取候选最终答案与检查点。铁律：**AI 不发明金标**，只做结构化——保存前逐项确认。
- **"✨ AI 起草领域包"**：给领域描述 + 3~5 道样例题，AI 起草领域包 JSON
  （剖面/材料声明/证据与口径要求/judge 提示/红线建议）。**红线与金标类内容必须人工审定**，
  保存后签名为 `llm-draft+human-reviewed`。
- 配置入口与边界见 [AI 辅助](ai-assist.md)。

## 4. 领域包：题库级判定配置（一次配好，全体题目继承）

题库详情页"领域包"卡显示当前生效的领域包（内置：bank/fb/locomo/longmem/tau/injection/
generic，按库名前缀自动匹配，也可手动绑定）：

| 领域包字段 | 作用 |
|---|---|
| profile + materials | 环境剖面与材料声明（发起评测时与 Agent 能力握手，不满足则 SKIPPED） |
| evidence_required / caliber_required | 答案是否必须附证据引用 / 口径声明（缺键扣结果质量分） |
| red_lines | 题库级红线：违禁工具、禁答正则（安全维一票项，出题人不重复填） |
| judge_hints / types | 自由题的 judge 评分提示、各题型默认键 |

在新领域接入时点"✨ AI 起草领域包"最快；也可以直接编辑 JSON 保存（存到数据卷
`packs/` 并绑定本题库）。判定系统怎么消费这些字段见 [评分规则](scoring.md)。
