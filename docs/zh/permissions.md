# 权限管理：四级角色与"我的跑法"

本文档说明平台的四级角色各自能做什么、账号怎么来、以及公共题库上的个人配置。
涉及的角色矩阵同样适用于页面按钮的显隐逻辑（无权限的功能不可见或只读）。

## 四级角色

| 能力 | owner | admin | member | viewer |
|---|---|---|---|---|
| 浏览题库与公开 run 历史 | ✓ | ✓ | ✓ | ✓ |
| 发起评测 / 查看自己的 run | ✓ | ✓ | ✓ | — |
| 查看所有人的 run | ✓ | ✓ | — | — |
| 创建私有题库 | ✓ | ✓ | ✓ | — |
| 创建/管理公共题库 | ✓ | ✓ | — | — |
| 用户管理（创建/重置密码/删除 member） | ✓ | ✓（不含 owner） | — | — |
| 平台设置（录制上游/保留期/注册开关） | ✓ | — | — | — |
| 修改 owner 密码 | 仅部署机 CLI | — | — | — |

- **账号来源**：owner 在首次部署时初始化（改密仅部署机 CLI：`docker exec agentgate-web
  agentgate passwd owner`）；admin/owner 在用户中心创建 member；viewer 可自助注册
  （平台设置里可关闭注册）。
- **用户中心**（右上角账号菜单）：改自己的密码（owner 除外）、AI 增强配置、admin 的
  用户管理、owner 的平台设置。

## 公共题库上的"我的跑法"

公共题库是全平台共享的（admin 维护题目本身），但每个 member/admin 可以有**不影响别人的
个人配置**（题库详情页）：

- **我的 level**：把某题在自己发起的评测里调成 L0/L1/L2（覆盖库默认）。
- **要跑**：把某题从自己的评测里剔除（下架勾选）。
- **一键恢复默认**：清空自己在这个库的全部个人配置。

发起评测时的实际生效顺序：先应用你的个人配置（剔除/改级），再套本次选择的 level 过滤。
私有题库没有这一层——创建者直接编辑题目本身。

## 与评审计分的关系

个人配置只影响"**谁跑、以什么 level 跑**"，不影响题库的金标与判定规则；同一道题不同人
跑出的六维分在题库总览页可横向比较（历史 run 列表带执行人）。
